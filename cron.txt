# 上科大场馆空闲看板 · 数据刷新规则（crontab 格式）
#
# 每行 5 个时间字段 + 1 个命令字段，与系统 crontab 完全一致：
#   分 时 日 月 周   命令
#
# 两种用法：
#   1) 内置调度器（跨平台，默认启用）：服务端读取本文件的 5 个时间字段，
#      按规则在进程内定时刷新，命令字段仅作注释用途。
#   2) 系统 cron / Windows 任务计划：把命令字段那条命令交给系统执行，
#      即 `npm run refresh`（一次性采集后退出）。
#
# 支持语法：*  |  */n  |  a  |  a-b  |  a-b/n  |  逗号列表 a,b,c
#   周字段 0 和 7 都表示周日；日与周同时被限定时按 crontab 惯例取“或”。

# 默认：每 10 分钟刷新一次
*/10 * * * *   node server/src/refresh.js

# 示例：工作日早八点到晚十点，每 5 分钟刷新（配合下面一行可同时生效）
# */5 8-22 * * 1-5   node server/src/refresh.js

# 示例：只在整点刷新
# 0 * * * *   node server/src/refresh.js

# 注意：OA 会被高频请求打扰，间隔不建议小于 5 分钟。
